👨‍💻 Sistema de Produtos em C++

Projeto desenvolvido em C++ com foco em prática de lógica de programação, organização de código e manipulação de dados.

Este repositório faz parte da minha evolução nos estudos de Desenvolvimento de Software, aplicando conceitos fundamentais de programação na prática.

🚀 Funcionalidades
Cadastro de produtos
Listagem de produtos
Manipulação de structs
Uso de vetores
Menu interativo no terminal
Organização de dados
Controle básico de estoque
🛠️ Tecnologias Utilizadas
C++
Visual Studio Code
Git & GitHub

Estruturas (struct)

Funções
Menus interativos
Entrada e saída de dados
Organização de código
Lógica de programação

Melhorar minhas habilidades em:

lógica de programação;
desenvolvimento back-end;
estruturação de sistemas;
